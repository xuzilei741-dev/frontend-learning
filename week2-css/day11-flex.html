Day 11 · Flex 布局

Flex 是前端工作中 80% 的布局方案。学完今天,水平居中、垂直居中、自适应布局都不是事。

1. Flex 是什么?为什么必学?

Flex(Flexible Box)是 CSS3 引入的一维布局方案。一维 = 一次只管一个方向(横或竖)。

对比 传统布局(float/position) Flex 布局
水平居中 margin: 0 auto(要知道宽度) justify-content: center(一行搞定)
垂直居中 定位 + transform(很麻烦) align-items: center(一行搞定)
自适应分配空间 要算百分比,容易错位 flex: 1(自动分配)
等高列 做不到(要 hack) 天然支持
学习成本 看似简单,坑很多 概念清晰,坑少
💡 核心概念:
Flex 有两个角色:
① 容器(flex container):设了 display:flex 的元素
② 项目(flex item):容器里的直接子元素
属性分两组:容器属性(管整体排列)+ 项目属性(管单个项目)

✅ 垂直居中神技:

  display: flex;
  justify-content: center;  /* 水平居中 */
  align-items: center;      /* 垂直居中 */
}
记住这两行,80% 的居中需求搞定。

6. flex 简写(项目属性,最重要!)

flex 是项目属性,控制项目如何分配剩余空间。3 个值: flex: grow shrink basis

简写 展开 含义
flex: 1 1 1 0% 等分剩余空间,可放大可缩小
flex: 2 2 1 0% 占 2 倍空间
flex: 0 0 200px 0 0 200px 固定 200px,不放大不缩小
flex: auto 1 1 auto 按内容大小分配
flex: none 0 0 auto 不参与分配,按原始尺寸

实测:flex: 1 vs flex: 2 vs flex: 0 0 120px

flex: 2
flex: 0 0 120px

看出来了吗?flex: 1 和 flex: 2 按 1:2 分配剩余空间,固定宽度的项目不参与分配。

7.2 order(调整排列顺序)

不改 HTML 顺序,用 CSS 控制显示顺序。默认 order 都是 0,数字越小越靠前:

HTML 第1个,order:3
HTML 第2个,order:1
HTML 第3个,order:2

实际显示顺序:B(1) → C(2) → A(3)

8. 综合练习:常见 UI 布局

用今天学的 Flex 实现 7 个常见 UI 模式,所有 CSS 写在 head 的 style 里。

要求清单(8 项)

  • ① 全局加 * { box-sizing: border-box; }(已写好)
  • ② .my-navbar 顶部导航:flex 容器、水平排列、justify-content: space-between、垂直居中、padding 12px 20px、背景 #fff、底部 border 1px solid #e5e7eb
  • ③ .navbar-menu 菜单容器:flex 容器、gap: 4px(菜单项之间间距)
  • ④ .my-card-grid 卡片网格:flex 容器、flex-wrap: wrap、gap: 16px、padding 16px、背景 #f9fafb
  • ⑤ .my-layout 主布局:flex 容器、gap: 16px、margin 16px 0
  • ⑥ .my-main 主内容区:flex: 1(自适应剩余空间,sidebar 固定 200px)
  • ⑦ .my-hero Hero 区:flex 容器、justify-content: center、align-items: center(水平+垂直居中)、margin 16px 0
  • ⑧ .my-vertical-menu 垂直菜单:flex 容器、flex-direction: column、gap: 4px、width 180px、margin 16px 0
💡 实战要点:
- 导航栏 = justify-content: space-between 经典用法
- 卡片网格 = flex-wrap: wrap + gap 组合拳
- 主内容自适应 = sidebar 固定宽度 + main 用 flex: 1
- 居中神技 = justify-content: center + align-items: center
