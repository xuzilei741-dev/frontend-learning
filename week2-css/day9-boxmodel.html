Day 9 · CSS 盒模型

盒模型是 CSS 布局的灵魂。不懂盒模型,后面写 Flex/Grid 都会踩坑。今天把它吃透。

1. 盒模型是什么?

浏览器把每一个 HTML 元素都看成一个「矩形盒子」,盒子从内到外有 4 层:

content(内容区)

从外到内依次是:

  • margin 外边距:盒子和其他元素之间的距离(透明)
  • border 边框:盒子的边
    • padding 内边距:边框到内容的距离(背景色会延伸到这里)
  • content 内容区:文字/图片实际显示的地方
记忆口诀:「外边距 → 边框 → 内边距 → 内容」,从外往里剥洋葱 🧅。

2. 盒子的实际尺寸(默认会"撑大"!)

这是盒模型最容易踩坑的地方。看这个例子:

/* CSS 默认行为(content-box) */
.box {
  width: 200px;
  padding: 20px;
  border: 5px solid red;
}

/* 实际在页面里占多宽?
   200 + 20*2(padding 左右) + 5*2(border 左右)
   = 200 + 40 + 10 = 250px ❌ 不是 200! */
⚠️ 新手大坑:你以为 width:200px 就是 200px,实际加上 padding 和 border 会变成 250px!布局全乱!

2.1 解决方案:box-sizing: border-box

加上一行魔法属性,让 width 直接包含 padding 和 border: 

.box {
  box-sizing: border-box;  /* 关键! */
  width: 200px;
  padding: 20px;
  border: 5px solid red;
}

/* 现在实际宽度就是 200px!
   padding 和 border 会"挤进" content 区域,
   content 自动变成 200 - 40 - 10 = 150px */
属性 content-box(默认) border-box(推荐)
width 含义 只算 content 含 content + padding + border
加 padding 会不会撑大盒子 会 ✗ 不会 ✓
加 border 会不会撑大盒子 会 ✗ 不会 ✓
日常推荐 不推荐 ⭐⭐⭐⭐⭐ 必用
✅ 全局推荐写法(以后每个项目都加): 
* {
  box-sizing: border-box;
}
用通配符 * 让所有元素都用 border-box,从此告别"盒子撑大"烦恼。

3. 块级 vs 内联元素的盒模型差异

不同 display 的元素,盒模型行为不一样:

对比项 块级(div / p / h1 / section) 内联(span / a / strong)
是否独占一行 是 否,多个并排
width / height 有效 无效(被内容撑开)
上下 margin 有效 无效
左右 margin 有效 有效
padding(上下) 有效,会撑大 有效,但不影响行高(会盖到上下行)

3.1 实测:内联元素上下 margin 无效

下面 span 我加了 margin: 30px,但上下根本不动,只有左右有间距:

这是一段文字,里面有个 内联元素 span(加了 margin:30px,但上下没动) 继续文字。

对比块级元素 div,上下 margin 完全有效:

我是 div(块级),上下 margin 8px 生效
第二个 div,中间有 16px 间距(8+8)
💡 结论:给 span、a、strong 这种内联元素设宽高、上下 margin 都是没用的。要让它们生效,先 display:inline-block 或 display:block。

4. margin 合并(垂直方向"取大值")

这是另一个坑:两个垂直相邻的块级元素,它们的上下 margin 不是相加,而是「取较大值」。

4.1 合并现象(默认)

下面两个 div,上面 margin-bottom:30px,下面 margin-top:20px,实际间距是 30px(取大值,不是 50px):

上盒子:margin-bottom:30px
下盒子:margin-top:20px(实际间距 = 30,不是 50)

4.2 阻止合并:触发 BFC

给下面盒子加 display:inline-block(或 overflow:hidden、float 等)就能阻止合并,此时间距 = 30 + 20 = 50px:

上盒子:margin-bottom:30px
下盒子:display:inline-block + margin-top:20px → 间距 = 50
📚 什么时候会发生合并?
① 相邻兄弟元素(如上)
② 父元素和第一个/最后一个子元素之间(无 border、padding、inline-block 阻隔时)
③ 空的块级元素(自己上下 margin 合并)

记住:只有垂直方向(margin-top / margin-bottom)会合并,水平方向(左右)永远不合并。

CSS 盒模型入门

盒模型是 CSS 布局的核心概念。每一个 HTML 元素都是一个矩形盒子,从内到外有四层:content、padding、border、margin。理解了这四层,后面写布局才不会踩坑。

最重要的一个属性是 box-sizing: border-box,它让 width 包含 padding 和 border,避免盒子被"撑大"。从此你设 width:600px,实际占的宽度就是 600px,不用再做加减法。

另一个常见现象是 margin 合并:两个垂直相邻的块级元素,它们的 margin 不是相加而是取大值。要让 margin 不合并,可以给元素加 inline-block 等触发 BFC 的属性。

最后,内联元素(如 span、a)的盒模型和块级不同:width、height、上下 margin 都无效。要让它们生效,需要先改 display。
