1. CSS 的三种写法

写法 1:行内样式(style 属性)

直接写在标签上,优先级最高,但复用性差:

我是红色、18px、加粗的文字

<p style="color:red; font-size:18px;">文字</p>

写法 2:内部样式表(style 标签)

写在 <head> 里的 <style> 标签中,本页面通用(本页大部分示例用的就是这种):

<head>
  <style>
    h4 { color: blue; }
  </style>
</head>

← 我就是 style 标签里 h4 选择器渲染的蓝色

写法 3:外部样式表(.css 文件)

把 CSS 写在单独的 .css 文件里,用 link 标签引入,多页共用(下周项目里会用):

<head>
  <link rel="stylesheet" href="style.css">
</head>
⚠️ 实际工作推荐:项目中统一用外部样式表(写 .css 文件),内部样式表偶尔用小页面 demo,行内样式只在极少数特殊场景用(比如动态改某个元素)。

2. 五大基础选择器(必须记熟!)

选择器 写法 匹配谁 使用频率
标签选择器 p { ... } 所有 <p> 标签 ⭐⭐⭐
class 选择器 .box { ... } 所有 class="box" 的元素(可重复使用) ⭐⭐⭐⭐⭐ 最重要!
id 选择器 #header { ... } id="header" 的元素(一页只能有一个) ⭐⭐
通配符选择器 * { ... } 所有元素 ⭐⭐(重置默认样式时用)
群组选择器 h1, h2, p { ... } h1 和 h2 和 p 都匹配 ⭐⭐⭐⭐

同一个 class 可以用多次,这是第二个 tip-box

id 选择器效果(上面 style 里写的 #unique-box):

3. 常用高级选择器

3.1 后代选择器(空格分隔)

选中「某个容器里面的某个后代」,不管隔了几层:

我在 article-demo 里面 → 被 .article-demo p 选中,变灰色。而且我的 strong 被变红色,因为 .article-demo p strong。

3.2 直接子元素选择器(>)

只选中「直接的儿子」,孙子不管:

我是 parent 直接儿子 → 被 .parent > p 选中,绿边框

我是 parent 的孙子(在 div 里面) → 不会被选,没有边框

3.3 伪类选择器 :hover(最常用)

鼠标悬停时改变样式,按钮交互必备:

📚 伪类还有这些(了解即可,以后会用到):
:active(点击按下时) / :focus(输入框获得焦点时) / :first-child(第一个子元素) / :nth-child(n)(第 n 个子元素)

4. 选择器优先级(冲突时听谁的?)

同一个元素被多个选择器同时命中时,按优先级决定用哪套样式:

权重从高到低:
!important  > 无敌,慎用
style="color:red"  > 行内样式(1000)
#id  > id 选择器(100)
.class / :hover / [attr]  > class 选择器(10)
p / h1 / div  > 标签选择器(1)
*  > 通配符(0)

示例:

/* class 权重 10 */
.red { color: red; }

/* 标签权重 1 → 干不过 class */
p   { color: blue; }

/* 最后 p.red 实际显示什么?
   答案:红色。因为 class 比标签权重大! */

<p class="red">我是什么颜色?</p>
💡 实战建议:尽量只用 class 选择器,不要用 id 和 !important,避免优先级打架。90% 的场景 class 够用。

为什么我要学前端开发

前端开发是一个看得见结果的技术领域——每当我写完一段代码,刷新浏览器就能立刻看到效果,这种反馈是我持续学习的最大动力。动手实践比看 10 遍教程都有效。

第二周开始学 CSS,把内容变得好看起来。字体、颜色、间距、布局——这些都是 CSS 的领域。Flex 布局是我重点要攻克的,因为前端工作中 80% 的布局都是靠 Flex 实现的。
