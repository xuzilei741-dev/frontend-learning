颜色和字体决定了页面的「气质」。今天学完,你就能把一篇干巴巴的 HTML 变成有设计感的文章。

关键字
写法 示例 特点 推荐场景
HEX(十六进制) #2563eb 最短、最常用 ⭐⭐⭐⭐⭐ 日常首选
RGB rgb(37, 99, 235) 数值直观,可读性强 ⭐⭐⭐ 偶尔用
RGBA rgba(37, 99, 235, 0.5) 第 4 个值是透明度 0~1 ⭐⭐⭐⭐ 半透明背景必备
HSL hsl(217, 83%, 53%) 色相/饱和度/明度,调色直观 ⭐⭐⭐ 需要配色时
颜色关键字 coral / red 140+ 个命名颜色 ⭐ 快速 demo
💡 实战建议:
① 主色用 HEX(最短)
② 需要半透明用 RGBA(如背景蒙层)
③ 需要调色板(同色系不同明度)用 HSL,改 L 值就行
④ 不要用关键字(red/blue),不专业且颜色有限

2. background 属性族

background 不只是背景色,它是一组属性,常用 6 个: 

.box {
  background-color: #2563eb;              /* 背景色 */
  background-image: url('bg.jpg');          /* 背景图 */
  background-repeat: no-repeat;            /* 不重复平铺 */
  background-size: cover;                 /* 覆盖整个容器 */
  background-position: center;           /* 居中显示 */
  background-attachment: fixed;          /* 滚动时不动(视差) */
}

/* 简写:一行搞定(顺序无要求,color 要在 image 后面) */
.box {
  background: #2563eb url('bg.jpg') no-repeat center/cover;
}

2.1 background-size 三个值对比

  • cover:覆盖容器(可能裁剪图片) — 最常用
  • contain:完整显示(可能留白)
  • 100px 100px / 100% 100%:精确尺寸

3. font 属性族

font 也是一组属性,决定文字长什么样: 

.text {
  font-family: -apple-system, "PingFang SC", sans-serif;
  font-size: 16px;           /* 字号 */
  font-weight: 400;         /* 字重:300细/400常规/700粗/900特粗 */
  font-style: italic;        /* 斜体 */
  line-height: 1.6;         /* 行高(无单位 = 字号倍数) */
}

/* 简写:顺序固定 size/line-height 必须挨着,family 放最后 */
.text {
  font: italic 700 16px/1.6 "PingFang SC", sans-serif;
}

3.1 系统字体栈(必背!)

不同系统默认字体不同,用「字体栈」让每个平台都用最佳字体: 

/* 苹果 / Windows / Linux 通吃,最推荐的写法 */
font-family: -apple-system, BlinkMacSystemFont, "PingFang SC",
  "Microsoft YaHei", sans-serif;

/* -apple-system:Mac/iOS 系统字体(San Francisco) */
/* BlinkMacSystemFont:Chrome on Mac */
/* "PingFang SC":苹果中文(萍方) */
/* "Microsoft YaHei":Windows 中文(微软雅黑) */
/* sans-serif:兜底无衬线字体 */
⚠️ 重要:中文字体名要加双引号("PingFang SC"),英文单词不用(sans-serif)。否则某些浏览器不识别。

3.2 font-weight 字重对比

300 Light 细 · 400 Regular 常规 · 700 Bold 粗 · 900 Black 特粗

注意:不是所有字体都有 9 个字重。系统字体通常只有 400/700,要更多字重需引入 Web 字体(如 Google Fonts)。

5. 综合练习:用颜色和字体美化文章

在下方动手区,用今天学的颜色 + 字体 + 文本样式,把一篇干巴巴的文章变好看。

要求清单(8 项)

  • ① 全局加 * { box-sizing: border-box; }(已写好)
  • ② 给 .my-article 加:背景色 #fff、字体栈 -apple-system, BlinkMacSystemFont, "PingFang SC", "Microsoft YaHei", sans-serif、字号 16px、行高 1.7、颜色 #1f2328
  • ③ 给 .my-title 加:颜色 #1f2328、字号 28px、字重 700、文字居中、字符间距 1px、底部 margin 8px
  • ④ 给 .my-subtitle 加:颜色 #2563eb、字号 20px、字重 600、左边框 4px solid #2563eb、左 padding 12px、上下 margin 20px
  • ⑤ 给 .my-paragraph 加:颜色 #4b5563、行高 1.8、首行缩进 2em、上下 margin 16px
  • ⑥ 给 .my-highlight 加:背景 #fef3c7、颜色 #92400e、padding 2px 8px、圆角 4px、字重 700
  • ⑦ 给 .my-divider 加:用 background 画线(不写 border 属性):高度 1px、背景色 #e5e7eb、上下 margin 24px、border: none(清掉 hr 默认边框)
  • ⑧ 给 .my-quote 加:背景 rgba(124, 92, 255, 0.08)(紫色半透明)、左 padding 16px、左 border 3px solid #7c5cff、斜体 italic、颜色 #6b7280、上下 margin 16px
💡 重点学习:
- ⑦ 用 background 画线是常见技巧,比 border 更灵活(能做渐变虚线等)
- ⑧ 用 rgba 做半透明背景,是卡片 UI 的核心技巧
- 字体栈一定要写完整,不要只写 "微软雅黑"

CSS 颜色与字体入门

为什么颜色很重要

颜色是页面的第一印象。好的配色能让用户停留更久,糟糕的配色会让人立刻关闭页面。前端开发中,我们通常从设计稿里取色,用 HEX 表示主色,用 RGBA 做半透明背景。

字体则决定了内容的可读性。系统字体栈能让每个平台的用户都看到最舒服的字体,不需要额外加载 Web 字体,性能也最好。

"好的排版是看不见的,读者只感受到舒服;坏的排版是刺眼的,读者只感觉到难受。" —— 排版格言

今天学的 5 种颜色表示法、6 个 background 子属性、font 简写、text-* 系列,加上系统字体栈,足以应付 80% 的日常样式需求。剩下的 20% 在响应式和动画里再学。
