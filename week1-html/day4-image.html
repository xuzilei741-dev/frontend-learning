1. 图片 img 标签

img 是自闭合标签,常用属性有:

  • src:图片地址(可以是本地路径或网络 URL)
  • alt:图片加载失败时显示的替代文字(必须加,给盲人/爬虫看)
  • width / height:设置图片宽高(像素或百分比)

2. 路径概念

2.1 绝对路径

完整的网址,从 http(s) 开头:

https://picsum.photos/300/200

优点:哪里都能访问;缺点:依赖网络和外部服务器

2.2 相对路径

相对于当前 HTML 文件的位置:

  • 同目录文件:images/demo.jpg
  • 上一级目录:../demo.jpg
  • 当前目录:./demo.jpg(通常可省略 ./)

优点:本地文件可离线访问;缺点:文件位置变了路径要改

3. 音频 audio 和视频 video(了解)

3.1 音频

需要本地 mp3 文件,取消注释即可使用。controls 属性显示播放控件。

3.2 视频

需要本地 mp4 文件,取消注释即可使用。常用属性:controls、width、height、autoplay、loop。

4. 找网站 Logo 的方法(国内可用)

推荐方案:favicon.cccyun.cc(国内可用,直接替换域名即可)

https://favicon.cccyun.cc/baidu.com

示例:

  • 百度: https://favicon.cccyun.cc/baidu.com
  • GitHub: https://favicon.cccyun.cc/github.com
  • DeepSeek: https://favicon.cccyun.cc/deepseek.com
  • 淘宝: https://favicon.cccyun.cc/taobao.com

备用方案(网站自带):在域名后面加 /favicon.ico

https://www.baidu.com/favicon.ico
