1. 什么是语义化?

语义化 = 用有意义的标签代替 div,让浏览器、搜索引擎、读屏软件都能看懂「这一块是干什么的」。

对比:

非语义化:
  <div class="header">网站标题</div>
  <div class="nav">导航</div>
  <div class="main">正文</div>

语义化:
  <header>网站标题</header>
  <nav>导航</nav>
  <main>正文</main>

好处:

  • SEO 友好:搜索引擎更容易理解页面结构
  • 无障碍:读屏软件(盲人用户)能正确朗读
  • 代码可读性:看标签名就知道这一块是干嘛的
  • 移动端适配:浏览器对语义标签有默认样式

2. 页面结构标签(最重要!)

一张典型的网页布局:

header(顶部:logo + 导航)
nav(导航条)
main(主体内容)

article(独立文章)
section(章节)
aside(侧边栏)
footer(底部:版权 + 链接)

八大结构标签

标签 作用 使用频率
<header> 页眉 / 区块的顶部 ⭐⭐⭐⭐⭐
<nav> 导航菜单(主要链接区) ⭐⭐⭐⭐⭐
<main> 页面主要内容(一页只有一个) ⭐⭐⭐⭐⭐
<article> 独立完整的内容(文章/评论/卡片) ⭐⭐⭐⭐
<section> 章节 / 区块(有标题的语义分组) ⭐⭐⭐⭐
<aside> 侧边栏 / 与主内容相关的辅助信息 ⭐⭐⭐
<footer> 页脚 / 区块的底部 ⭐⭐⭐⭐⭐
<figure> 图文组合(图 + 说明) ⭐⭐

示例:标准页面骨架

<body>
  <header>
    <h1>网站标题</h1>
    <nav>
      <ul>
        <li><a href="#">首页</a></li>
        <li><a href="#">关于</a></li>
      </ul>
    </nav>
  </header>

  <main>
    <article>
      <h2>文章标题</h2>
      <p>正文...</p>
      <section>
        <h3>第一段</h3>
        <p>内容...</p>
      </section>
    </article>

    <aside>
      <h3>相关推荐</h3>
      <ul>
        <li>推荐文章 1</li>
      </ul>
    </aside>
  </main>

  <footer>
    <p>© 2026 我的网站</p>
  </footer>
</body>

4. figure + figcaption(图文组合)

用于「图片 + 说明文字」的组合,说明文字用 figcaption:

代码:

<figure>
  <img src="mdn.png" alt="MDN Logo">
  <figcaption>图 1:MDN 官网 logo</figcaption>
</figure>

5. 综合练习:用语义化标签重构个人主页

任务:在下方动手区,用语义化标签写一个完整的个人主页,把本周学过的所有标签整合起来。下面是结构要求:

区域 用到的标签 内容建议
页眉 header + h1 + nav 网站名 + 导航(首页/文章/关于)
主体 main + article + section 至少 1 篇文章,内含 ≥2 个 section
侧边栏 aside 相关推荐或个人信息
页脚 footer 版权 + 联系方式
图文 figure + figcaption 1 张图 + 说明
时间 time 文章发布日期
引用 blockquote 1 段名言引用

硬性要求清单:

  • ✅ 用 <header> 包顶部,内有 <h1> + <nav>
  • ✅ nav 里至少 3 个导航链接(用 ul + li + a)
  • ✅ 用 <main> 包主内容
  • ✅ main 内至少 1 个 <article>,article 内至少 2 个 <section>
  • ✅ 每个 section 都要有 <h2> 或 <h3> 标题
  • ✅ 用 <aside> 做侧边栏
  • ✅ 用 <footer> 包底部,内有版权信息和联系方式
  • ✅ 至少 1 个 <figure> + <figcaption>
  • ✅ 至少 1 个 <time> 标签(datetime 属性)
  • ✅ 至少 1 个 <blockquote>
  • ✅ 综合用之前学过的 p / ul / a / img / hr / strong / em
