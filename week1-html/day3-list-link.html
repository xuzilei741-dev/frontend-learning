无序列表 ul

用于没有顺序关系的项目列表,默认显示为圆点。

  • HTML 超文本标记语言
  • CSS 层叠样式表
  • JavaScript 脚本语言

有序列表 ol

用于有顺序关系的项目,默认显示为阿拉伯数字。

  1. 打开 VS Code
  2. 新建 index.html
  3. 输入代码并保存
  4. 用浏览器打开预览

定义列表 dl

用于「术语 - 解释」结构,dt 是 term(术语),dd 是 description(描述)。

HTML
超文本标记语言,负责网页的结构。
CSS
层叠样式表,负责网页的样式。
JS
JavaScript,负责网页的交互。
