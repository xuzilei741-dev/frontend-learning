1. 表单 form 基础

表单 = 用户输入 + 提交给后端。核心标签:

  • form:表单容器,里面所有输入都属于这张表单
  • label:输入框文字标签,点 label 文字光标会跳到对应输入框
  • input:最常用输入标签,靠 type 属性决定种类(十几种)
  • textarea:多行文本输入框
  • select + option:下拉选择框
  • button:按钮,type="submit" 就可以提交表单

4. 常用输入属性

  • placeholder:输入框内提示文字(没输入时的灰字)
  • value:默认值,text/password/number 等 type 自带的初始内容
  • checked:radio / checkbox 默认选中
  • selected:option 默认选中
  • disabled:禁用,不可编辑也不提交
  • required:必填,空着点提交会弹浏览器的红色提示
  • maxlength:最大输入字符数
  • min / max:number/date/range 的最小/最大值

5. 练习区:用户注册表单

任务:在下面动手区写一张完整的用户注册表单,参考实际注册页常用字段。下面是建议结构:

字段名 输入类型 说明
用户名 text placeholder「3~12 位字符」,maxlength=12,required
密码 password placeholder「至少 6 位」,required
确认密码 password required
邮箱 email required
手机号 tel placeholder「11 位手机号」
性别 radio(男/女/其他) name 必须相同,默认选中男
生日 date
所在城市 select 至少 4 个 option,含一个「请选择」空值
兴趣爱好 checkbox(3+ 项) name 相同,至少 1 项默认勾选
个人简介 textarea rows="4" placeholder「介绍一下你自己...」
同意协议 checkbox required(必须勾才能提交)
注册按钮 input type=submit 或 button type=submit 按钮文字「立即注册」

硬性要求清单:

  • ✅ 外层必须用 <form> 标签包起来
  • ✅ 每个输入框都要有 name 属性(否则提交时不带上这个字段)
  • ✅ 至少用 6 种不同的 input type(text/password/email/tel/radio/checkbox/date 中任选)
  • ✅ 有 1 个 select 下拉框,含 ≥4 个 option
  • ✅ 有 1 个 textarea 多行文本
  • ✅ 有 1 组 radio(≥3 个选项,name 相同)和 1 组 checkbox(≥3 个选项,name 相同)
  • ✅ 至少 3 处 required 必填项
  • ✅ 至少 2 处默认值(checked / selected / value 都行)
  • ✅ 有一个 submit 提交按钮
